# 실습과제1
- 16MB의 범위는 $16 \times 2^{20}$이므로 주소는 $0 ~ (16 \times 2^{20}-1)$ 까지 있다.
- 변수의 주소는 메모리 속 각각 다른 변수들의 차지하고 있는 공간의 시작 번지로 부른다.\
  변수가 저장되는 주소는 프로그래머가 원하는대로 저장할 수 없고 자동으로 컴퓨터에 의해 결정된다.
- 변수의 주소의 자료형은 모두 다르게 존재한다.
  * 변수 i의 주소 5번지 -> int형(4바이트)을 가리키는 주소
  * 변수 c의 주소 8번지 -> char형(1바이트)을 가리키는 주소
  * 변수 f의 주소 12번지 -> float(4바이트)을 가리키는 주소
  * 변수 d의 주소 16번지 -> double(8바이트)을 가리키는 주소
