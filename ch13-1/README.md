## 실습과제1
- **배열명**이란 배열의 첫번째 요소의 주소
- 배열표현과 포인터(주소) 표현의 변환 공식은 다음과 같다.

  | |배열표현 |포인터(주소) 표현|
  |:---:|:---:|:---:|
  |**배열요소의 값**|a[i]|*(a+i)|
  |**배열 요소의 주소**|&a[i]|a+1|
  
- 배열의 주소는 첫번째 요소를 기준으로 메모리 주소가 이어져 있기 때문에 배열명을 알게되면 모든 원소의 주소를 구하는 것이 가능하다.
- 배열의 주소는 첫번째 요소를 기준으로 메모리 주소가 이어져 있기 때문에 배열명을 알게 되면 모든 원소의 주소를 통해 값을 구하는 것이 가능하다.
- 포인터에 대해 가능한 연산의 종류와 의미는 아래와 같다.
  
  |수식|의미|
  |:---:|:---:|
  |p + n|p + n*|
  |P - n|p - n*|
  |p++|p = p +|
  |p--|p = p -|
  
  *여기서 p는 포인터를 n은 정수를 의미한다.
  *포인터가 가리키는 자료형에 따라 더하는 정수의 크기도 달라진다.
  
  |포인터가 가리키는 자료형|자료형 크기|
  |:---:|:---:|
  |char|1|
  |int|4|
  |double|8|
  
  *변하는 자료형의 크기는 메모리가 가지는 용량과 같다.
- 예시로 포인터에 1을 더하면 자료형의 크기만큼 주소가 이동하게 됩니다. 이와 같이
포인터 연산은 자동으로 처리하여 코드의 가독성을 높일 수 있습니다.
